# CI Integration

AgentPerf's CI path is filesystem-first: keep or retrieve a reviewed baseline
artifact, generate a candidate artifact in the pull request, then run
`agentperf check` with an explicit regression policy.

## Baseline

A reviewed baseline is an AgentPerf artifact that represents accepted behavior
for a workload. It should include task outcomes or quality scores when quality
matters.

Common patterns:

- commit a small reviewed baseline artifact for deterministic local workloads;
- download a reviewed baseline from a release artifact or internal storage;
- refresh the baseline only through a human-reviewed update.

Do not use an unreviewed PR candidate as its own baseline.

## Candidate

The candidate artifact is generated by the PR's current code. For example:

```bash
python examples/bring_your_own_agent/run.py --variant optimized --output-root runs
agentperf doctor runs/optimized
```

`doctor` should be run before `check` so CI logs explain whether capture is
complete enough for the intended conclusion.

## Regression Policy

`agentperf check` compares baseline and candidate artifacts with a policy:

```bash
agentperf check \
  baselines/support-agent \
  runs/optimized \
  --policy agentperf-regression.yaml
```

Exit codes:

- `0`: `PASS`
- `1`: `FAIL`
- `3`: `INCONCLUSIVE`
- `2`: invalid input, malformed policy, or command error

`PASS` means the candidate stayed within the configured quality, performance,
finding, and task-coverage rules. `INCONCLUSIVE` means evidence was insufficient
for the policy, not that the candidate is good.

## GitHub Actions

A copyable workflow is available at:

[../examples/github_actions/agentperf-regression.yml](../examples/github_actions/agentperf-regression.yml)

The example uses `agentperf demo` because it is deterministic and requires no
API key, GPU, or model service. In a real repository, replace the demo step with
your agent's candidate-artifact generation command and point `agentperf check`
at your reviewed baseline artifact.

Until AgentPerf is published on PyPI, the copyable workflow installs from the
GitHub source package. After publication, replace that install command with:

```bash
pip install agentperf
```

## Artifact Retention

For debugging failed checks, upload the candidate artifact and HTML report as
GitHub Actions artifacts. AgentPerf does not require a hosted artifact registry.

Example:

```yaml
- uses: actions/upload-artifact@v4
  if: always()
  with:
    name: agentperf-candidate
    path: |
      runs/candidate
      agentperf-report.html
```

Avoid uploading secrets, private prompts, or raw model/server logs.
